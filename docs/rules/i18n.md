# i18n Rules — Vue 3 / vue-i18n

## Quy tắc bắt buộc

- **Không bao giờ hardcode chuỗi hiển thị** trực tiếp trong `.vue` hay `.js` — luôn dùng `t('key')`.
- Mọi text người dùng thấy (label, tooltip, placeholder, thông báo, ...) đều phải có i18n key.

## Cấu trúc locale

Mỗi feature có 2 file locale song song:

```
admin/src/i18n/locales/
├── vi/[feature].json   ← Tiếng Việt
└── en/[feature].json   ← Tiếng Anh
```

**Khi thêm key mới: phải cập nhật cả `vi/` lẫn `en/` cùng lúc.** Thiếu một locale → text hiển thị dưới dạng key thô (ví dụ `orders.newManualOrder`).

## Cách thêm key

1. Xác định file phù hợp (`nav.json`, `orders.json`, `common.json`, ...).
2. Thêm key vào `vi/[file].json` với bản dịch tiếng Việt.
3. Thêm key vào `en/[file].json` với bản dịch tiếng Anh — **ngay sau bước 2, không để sau**.
4. Dùng `t('namespace.key')` trong template/script.

## Ví dụ

```json
// vi/orders.json
"newManualOrder": "Nhập thủ công"

// en/orders.json
"newManualOrder": "Manual Entry"
```

```html
<!-- ✅ Đúng -->
<span>{{ t('orders.newManualOrder') }}</span>
<prime-button v-tooltip.top="t('orders.newManualOrder')">

<!-- ❌ Sai — hardcode -->
<span>Nhập thủ công</span>
<prime-button v-tooltip.top="'Manual Entry'">
```

## Tooltip

Tooltip cũng phải dùng i18n — không hardcode string trong `v-tooltip`:

```html
<!-- ✅ -->
<prime-button v-tooltip.top="t('orders.kanban')">

<!-- ❌ -->
<prime-button v-tooltip.top="'Kanban'">
```

## Key naming convention

- Dùng camelCase: `newOrder`, `markPaid`, `clearFilters`
- Nhóm theo context: `filter.title`, `list.col.orderNumber`, `create.optionsDialog.quantity`
- Tên key mô tả ý nghĩa, không mô tả vị trí UI

## File nào chứa key nào

| File | Nội dung |
|------|----------|
| `nav.json` | Labels trong sidebar navigation |
| `common.json` | Text dùng nhiều nơi (save, cancel, delete, ...) |
| `[feature].json` | Text chỉ dùng trong feature đó |
| `sidebar.json` | Brand name, tiêu đề sidebar |
